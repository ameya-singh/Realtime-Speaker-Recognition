# 🎙️ Voice Recognition System

A real-time speaker recognition system built with **ECAPA-TDNN (SpeechBrain)**, **PyTorch**, and a **Tkinter GUI**.

## 🚀 Features
- Register new speakers with 3 voice samples
- Recognize speakers in real-time
- Delete speakers from the database
- Persistent storage with `.pt` database
- User-friendly GUI with Tkinter

## 🛠️ Technologies
- Python, PyTorch, SpeechBrain
- Torchaudio, NumPy, SciPy, SoundDevice
- Tkinter (GUI)
